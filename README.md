# MindVault 2.0 - Sistema Operacional de Vida & Centro de Clareza Mental

[![GitHub Repository](https://img.shields.io/badge/GitHub-josef10000%2Fmindvault-black?logo=github)](https://github.com/josef10000/mindvault)

**MindVault 2.0** é uma plataforma autoral de clareza mental e desenvolvimento pessoal projetada com uma estética **100% Monocromática (Pure Black & White)** de alto contraste.

---

## 🌟 Arquitetura Autoral & Módulos

1. **Página de Acesso & Showcase Integrado**:
   - Apresentação visual e explicativa dos 4 pilares do sistema integrada diretamente na tela de autenticação.
2. **Matriz de Vida & Clareza Mental (Life Matrix)**:
   - Medidores de equilíbrio para as 5 áreas vitais (Saúde, Conhecimento, Carreira, Finanças e Desenvolvimento Pessoal).
   - Gerenciador de Metas anuais com marcadores visuais.
3. **Nexo de Conhecimento por Radar (Knowledge Nexus)**:
   - Mapeamento de pensamentos em um radar monocromático de órbitas de conhecimento e fios de associação por `#Tags`.
4. **Registros do Vault (Vault Registers)**:
   - **Acervo de Leitura**: Status, páginas, avaliações e fichamentos.
   - **Fichas de Treino Semanal**: Exercícios e controle de rotina.
   - **Check-in de Hábitos**: Rastreamento de sequências diárias.
5. **Câmara de Foco & Diário Silencioso (Focus Chamber)**:
   - Imersão com Timer Pomodoro digital e diário de clareza mental (*Brain Dump*).
6. **Extensões Autorais (Vault Extensions)**:
   - Gerenciador de extensões e módulos da comunidade.

---

## 🛠️ Stack Tecnológica

- **Frontend**: Next.js 15+ (App Router), React 19, TypeScript.
- **Estilização**: TailwindCSS (Pure Black & White Theme) + Lucide Icons.
- **Backend & Cloud Services**: Firebase (Auth, Cloud Firestore NoSQL, Firebase Storage).
- **Hospedagem & CI/CD**: Vercel + GitHub Actions.

---

## 🚀 Execução Local

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000` no seu navegador.
